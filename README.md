# Project Pro Running

Insights from race meetings across the Victorian Athletic League (VAL), South Australian Athletic League (SAAL), and other organisations governed by the Australian Athletics Confederation (AAC).

---

## Data Sources

Results are collected from publicly available websites and archived pages where available.

Including:

- [Victorian Athletic League (VAL)](https://val.org.au/)
- [South Australian Athletic League (SAAL)](https://saal.org.au/)
